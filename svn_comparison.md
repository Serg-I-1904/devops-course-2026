# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN - "дорогое"?

В Git ветка - это лёгкая ссылка на коммит. Создание ветки почти мгновенное и не требует копирования файлов. В SVN ветвление исторически связано с копированием директорий внутри центрального репозитория, поэтому операция тяжелее и сильнее зависит от сервера.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, полноценный коммит в SVN без интернета сделать нельзя, потому что SVN использует централизованную модель. История хранится на центральном сервере, и для фиксации изменений нужно подключение к нему. В Git можно делать локальные коммиты без сети, потому что у разработчика есть полная копия репозитория.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может быть удобен в legacy-проектах, где уже есть старая инфраструктура и процессы вокруг централизованного репозитория. Также он может подойти командам, которым нужна простая модель с одним центральным источником правды и строгим контролем доступа к отдельным каталогам.
