# Git в VS Code

## Что удобно

1. Панель Source Control сразу показывает изменённые файлы и помогает не забыть добавить нужный файл в коммит.
2. Встроенный diff удобно показывает, какие строки были добавлены или изменены перед коммитом.
3. GitLens помогает быстро понять, кто и когда менял строки, без ручного вызова git blame.

## Что удобнее делать в терминале

Сложные операции с историей, например rebase, cherry-pick и просмотр графа коммитов, удобнее выполнять в терминале, потому что команды явно показывают, что происходит с репозиторием.
